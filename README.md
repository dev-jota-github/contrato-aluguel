# Contrato de Aluguel

App web (HTML + CSS + JS puro, sem instalação) que gera um contrato de locação residencial em PDF, passo a passo, baseado no modelo enviado.

## Publicar no GitHub Pages (acessar de qualquer lugar)
1. Crie um repositório no GitHub e envie `index.html`, `style.css`, `app.js` (pelo botão *Add file → Upload files*).
2. Vá em **Settings → Pages**, em *Branch* escolha `main` / `(root)` e salve.
3. Em ~1 minuto o app abre em `https://SEU-USUARIO.github.io/NOME-DO-REPO/`.

## Como funciona
Locador → Locatário → Imóvel → Prazo e valor → Perguntas sim/não (animais, utensílios, contas, atrasos, honorários, multa) → Revisão de cláusulas (editar/remover/adicionar) → Contrato pronto → **Baixar PDF** (usa “Salvar como PDF” do navegador).

Aviso: modelo genérico; para casos específicos, consulte um advogado.
